# Objectives for Module 12 – Secure File and Resource Handling

This module covers the risks that arise when an application accepts, stores, and serves files, builds file paths from user input, or fetches resources from addresses that users supply.

A successful candidate can:

- Identify the risks of accepting uploaded files, including malicious content, disguised file types, and excessive size
- Distinguish the checks applied to file extension, declared content type, and file content, and recognize why the client-declared values cannot be trusted
- Recognize how user-controlled file names, paths, and archive entries enable path traversal, Zip Slip, and file inclusion
- Identify secure locations and access controls for stored files, including cloud storage with pre-signed URLs
- Recognize the response headers that make downloaded files safe to serve
- Identify the risks of temporary files and the controls that reduce them
- Recognize how server-side request forgery (SSRF) occurs when the server fetches a user-supplied address
- Distinguish SSRF controls such as allowlists, network restrictions, and response handling

## Expected competency

Candidates can review a feature that uploads, stores, downloads, or imports files from a URL.
They can identify where user-controlled values reach the file system or the network, and which controls and response headers address each risk.
