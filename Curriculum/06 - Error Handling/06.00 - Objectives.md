# Objectives for Module 6 - Error Handling

This module covers how an application detects, handles, and reports errors and exceptional conditions without exposing information or weakening security controls.
Logging of errors is covered in Module 7.

A successful candidate can:

- Identify how mishandled errors and exceptional conditions lead to security weaknesses
- Recognize secure exception-handling practices and the weaknesses of unsafe ones
- Distinguish safe error messages from messages that disclose internal information
- Distinguish fail-secure behavior from fail-open behavior
- Recognize the role of centralized and last-resort error handlers
- Identify which error details belong in user-facing responses and which belong only in internal records
- Distinguish development error behavior from production error behavior

## Expected competency

Candidates can recognize error-handling code and configuration that exposes internal details or lets a failure bypass a security control.
They can identify the error-handling practices that keep an application secure when something goes wrong.
