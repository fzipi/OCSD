# Objectives for Module 7 - Secure Logging

This module covers how an application records security-relevant events so that attacks can be detected and investigated, without exposing sensitive data or giving attackers a way to tamper with the records.

A successful candidate can:

- Identify the security-relevant events an application should log and the risks of insufficient logging
- Recognize the information a log entry needs to support an investigation
- Distinguish data that may be logged from data that must be excluded, masked, or hashed
- Identify log injection and the controls that protect log content, access, and integrity
- Recognize secure use and configuration of logging libraries, including the purpose of log levels
- Distinguish logging from monitoring and alerting, and recognize why central, separate log storage matters

## Expected competency

Candidates can recognize whether an application logs the events needed to detect and investigate an attack.
They can identify logging practices that expose sensitive data or allow log tampering.
