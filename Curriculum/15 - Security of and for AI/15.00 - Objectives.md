# Objectives for Module 15 – Security of and for AI

This module covers the security risks developers face when they build applications on large language models (LLMs) and AI agents.
Part A covers the OWASP Top 10 for LLM Applications 2026.
Part B covers agentic applications and the Model Context Protocol (MCP).

A successful candidate can:

- Identify the ten risks of the OWASP Top 10 for LLM Applications 2026 by name and number
- Recognize why an LLM cannot reliably separate instructions from data
- Distinguish direct from indirect prompt injection
- Recognize that model output is untrusted input to whatever consumes it
- Recognize that hidden context, such as a system prompt, can be discovered and must not protect a secret or enforce a control
- Identify exposure paths for sensitive data through prompts, retrieved content, logs, and embeddings
- Recognize risks from model, dataset, and package supply chains and from poisoned training, fine-tuning, and retrieval data
- Identify risks from misinformation and unbounded consumption
- Distinguish an LLM application from an agent that can call tools and take actions
- Identify excessive functionality, permissions, and autonomy as causes of excessive agency
- Recognize the risk areas of the OWASP Top 10 for Agentic Applications 2026
- Recognize the main MCP security risks and controls

## Expected competency

Candidates can recognize security risks in an application that uses an LLM, retrieval, or agent tools.
They can identify which Top 10 risk a described weakness belongs to and which kind of control reduces it.
