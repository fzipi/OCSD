# Objectives for Module 5 - Cryptography and Key Management

This module tests the developer for the secure use of cryptography in applications / APIs.

A successful candidate can:

- Differentiate encryption from hashing from encoding
- Apply cryptographic solutions appropriately for security properties such as confidentiality, integrity, and authenticity
- Select secure cipher suites and algorithms while avoiding deprecated options
- Implement proper key management including generation, storage, rotation, and deletion
- Recognize and defend against common cryptographic attacks

---

## Expected competency
Candidates can implement cryptographic solutions by selecting libraries, apply cryptography for authentication and secure credential storage. The candidate factors in key lifecycle management while implementing solutions.
