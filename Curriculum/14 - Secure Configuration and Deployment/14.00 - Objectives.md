# Objectives for Module 14 - Secure Configuration and Deployment

This module covers the security of the environment that runs an application and of the process that delivers code to it.
It covers web servers, managed hosting platforms, container images, secrets, deployment packages, and build pipelines.

A successful candidate can:

- Identify secure web server settings for file locations, file permissions, and the identities that run the server and the application
- Recognize files, features, debug code, and dependencies that must not be present in a production deployment
- Distinguish the security responsibilities of the platform provider from those of the application team on managed hosting platforms
- Recognize insecure default settings and backdoors, and identify secure defaults that fail closed
- Identify insecure and secure ways to store, deliver, rotate, and revoke secrets in deployed applications
- Recognize the purpose and limits of package signing, commit signing, and image signing, and what a verifier must check
- Distinguish the security headers that a deployment configures, and identify where Modules 4, 9, and 13 cover them
- Recognize common attack paths against build and deployment pipelines, and identify controls that reduce them
- Identify unsafe container image and runtime settings

## Expected competency

Candidates can review a deployment description and identify insecure configuration.
They can recognize embedded secrets, excessive privileges, unsigned or unverified artifacts, and unnecessary exposure.
They can select a safer alternative for each.
