# Objectives for Module 2 - Authentication and Credential Management

This module covers how web applications verify identities, protect credentials, maintain authenticated sessions, and validate tokens and assertions.

A successful candidate can:

- Distinguish authentication from identification, identity proofing, and authorization
- Distinguish authentication methods and factors for human and non-human identities
- Identify protections for passwords and other credentials throughout their lifecycle
- Recognize the security properties and limitations of multi-factor authentication (MFA), passkeys, and other passwordless authentication
- Identify requirements for establishing, maintaining, renewing, and terminating authenticated sessions, including cookie attributes and caching of authenticated content
- Recognize how cross-site request forgery (CSRF) works and distinguish the controls that prevent it
- Distinguish single sign-on (SSO), federation, OAuth 2.0, OpenID Connect (OIDC), and Security Assertion Markup Language (SAML)
- Identify validation and revocation requirements for self-contained tokens, including JSON Web Tokens (JWT), and for federation assertions
- Identify common authentication and session failures and the test cases that reveal them

## Expected competency

Candidates can recognize whether an authentication design protects human and non-human identities, credentials, and sessions.
They can identify weaknesses in login, recovery, MFA, passkeys, federation, token validation, request forgery protection, and session handling.
