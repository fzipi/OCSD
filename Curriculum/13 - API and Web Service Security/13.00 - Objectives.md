# Objectives for Module 13 - API and Web Service Security

This module covers the security risks of application programming interfaces (APIs) and web services, and the controls that reduce those risks.
It focuses on how APIs differ from browser-based applications and how common web security controls apply to them.

A successful candidate can:

- Identify the risks in the OWASP API Security Top 10:2023
- Distinguish API authentication from API authorization, and recognize the credentials and tokens APIs use
- Recognize the controls that limit resource consumption and automated abuse of APIs
- Recognize request validation and response handling controls for APIs
- Distinguish the security concerns of REST, GraphQL, SOAP, and gRPC APIs
- Identify the risks of webhooks and of consuming third-party APIs, and the checks that reduce them
- Identify approaches for testing API security

## Expected competency

Candidates can review an API description or design and identify missing authentication, authorization, validation, and rate-limiting controls.
They can recognize which OWASP API Security Top 10 risk an observed weakness represents.
They can identify the API-specific concerns of a given API style, webhook, or third-party integration.
