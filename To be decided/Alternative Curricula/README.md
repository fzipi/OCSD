# Alternative Curricula for Application Security

When putting together a new curriculum, consider prior art: what other organizations have written and published as best practice.
Comparing against it helps identify gaps between what has been published and what has been effective in industry.

From a UK and international perspective, consider the [Cyber Security Body of Knowledge (CyBOK)](https://cybok.org).
For application security, CyBOK has three knowledge areas under the Software and Platform Security grouping:

- Software Security
- Web & Mobile Security
- Secure Software Lifecycle

In addition to the descriptive documents, the knowledge trees can be used to identify individual categories and details when documenting an application security curriculum for certification.
See [CyBOK](./CyBOK/CyBOK.md) for the local copies and their licensing note.
